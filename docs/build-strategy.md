# Initial scope

Element starts with three rare-earth projects and an evidence-first comparison workflow. Apple-inspired typography, monochrome surfaces and glass navigation support a working dashboard. All issuer data are snapshots checked on 2026-10-04, with publication dates shown where available. No live-market or comprehensive-coverage claim.

The scenario calculator uses user assumptions only: USD/kg price and cost, tonnes/year production, USD million initial capex, operating years, discount rate and delay. Initial capex occurs at time zero; annual operating cash flow begins in year one plus delay. No IRR is presented without a full project cash-flow model.

Backend: FastAPI and Pydantic. Frontend: React and Vite. Initial data live in a versioned Python module; a database is unnecessary until ingestion and version history are implemented. Initial opinions are explicitly editorial. DeepSeek integration follows evidence ingestion.

Checks: deterministic numerical unit tests, API contracts, production build, responsive CSS and browser review if the available browser surface permits it.
